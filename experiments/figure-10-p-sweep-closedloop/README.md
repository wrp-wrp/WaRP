## Directory layout

This directory has four slots. Committed = checked into git (paper
truth); output = regenerated by scripts (gitignored).

| Path | What | State |
|---|---|---|
| `*.pdf` / `*.tex` (directly under this dir) | **authoritative** paper figure / table that paper TeX's `\includegraphics` references | committed |
| `data/paper/` | **authoritative** frozen input data used to render the paper figure | committed, SHA-256 hashed in `experiments/DATA_MANIFEST.json` |
| `_regen/` | light-mode regenerated figure (from `data/paper/`); written by `bash scripts/run_all.sh --profile light` | gitignored |
| `data/latest/` | runner's fresh output data; written by `./run.sh` or `bash scripts/run_all.sh` (full mode) | gitignored |
| `_latest/` | artifact rendered from fresh `data/latest/`; written by `./render.sh` or full `run_all.sh` | gitignored |

`./render.sh` reads fresh `data/latest/` and writes `_latest/`;
`./render.sh light` reads committed `data/paper/` and writes `_regen/`.
Neither command replaces paper evidence or authoritative artifacts. Promotion
is explicit and followed by `python3 -m artifact freeze`.

## Running

```bash

./render.sh

# Light profile (render-only from frozen data, ~seconds, no network):
./render.sh light
```

Both scripts delegate to `python3 -m artifact`; commands come from
`artifact/registry.py`.
