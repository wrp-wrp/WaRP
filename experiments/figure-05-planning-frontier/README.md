# Planning frontier

**Paper figure:** 5

**Paper label:** `fig:planning-frontier`

This Figure Experiment owns the deterministic two-panel illustration of the
feasible `(B, W)` plan cloud and its lower Pareto frontier. It is an explanatory
synthetic figure rather than a measured benchmark, so it has no data-collection
Stage or external service dependency.

## Reproduce

```bash
./render.sh
```

The renderer uses a fixed NumPy seed and writes
`figure_planning_bw_frontier.pdf` in this directory. The PDF is the committed
Paper Artifact.
